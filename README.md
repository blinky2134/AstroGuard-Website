# AstroGuard Website

AstroGuard's static product website, built with HTML/CSS/vanilla JavaScript for GitHub Pages.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. GitHub will publish the site at `https://blinky2134.github.io/AstroGuard-Website/` once deployment completes.

## Site notes

- The checkout buttons link to Stripe-hosted payment pages for the five case colours. These are live payment links and can accept real orders.
- The interactive screen gallery is a product showcase; it does not connect to a physical AstroGuard, PHD2, weather provider or live aurora service.
- The site uses Google Fonts remotely and includes product and astrophotography images from local files and external hosts.
