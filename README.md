# AstroGuard Website

First static website prototype for AstroGuard. The site is plain HTML/CSS/JavaScript and is intended for GitHub Pages.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. GitHub will publish the site at `https://blinky2134.github.io/AstroGuard-Website/` once deployment completes.

## Prototype notes

- The interactive device preview uses illustrative sample data and is not connected to a physical AstroGuard, PHD2, weather provider or live aurora service.
- The satellite panel is a visual placeholder pending a confirmed screenshot/reference from the device.
- No payment processing, customer accounts, API credentials or live data integrations are included.
- The site currently uses Google Fonts remotely; a locally hosted font can be added later if desired.
- Product photography and the original demonstration video are not embedded in this first commit; these can be added after preparing optimised, appropriately licensed assets.
